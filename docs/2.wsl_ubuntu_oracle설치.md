# SQL 실습을 위한 oracle 설치 방법
## 0. 설치 환경 및 조건
* **WSL2 Ubuntu**: Docker 실행
* **Oracle AI Database 26ai Free**: 컨테이너
* **Docker Compose**: 설치 및 관리
* **관리자 계정**: `SYS`, `SYSTEM`
* **실습 사용자 계정**: `joy`
* **Windows 호스트**: DBeaver에서 `localhost:1521`로 접속

Oracle Free는 기본적으로 CDB `FREE`, PDB `FREEPDB1`을 생성하며 변경할 수 없다.  
관리자 비밀번호는 `ORACLE_PWD`로 설정할 수 있고, 사용자 계정은 초기화 SQL로 생성하는 방식이 적절하다. ([Oracle Docs][1])

## 1. 전체 구성

```text
Windows 11
│
├─ DBeaver
│    └─ localhost:1521/FREEPDB1
│
└─ WSL2 Ubuntu
     │
     └─ Docker
          └─ Oracle AI Database 26ai Free
               │
               ├─ CDB : FREE
               ├─ PDB : FREEPDB1
               ├─ 관리자 : SYS / SYSTEM
               └─ 사용자 : JOY
```

여기서 Oracle에는 MySQL의 `root`라는 DB 계정이 따로 없다. **`SYS`가 사실상 최상위 관리자 계정이며 `SYSTEM`이 일반 관리 작업용 계정**이라고 이해하면 된다.

# 2. 작업 폴더 생성

WSL Ubuntu에서 다음을 실행한다.

```bash
mkdir -p ~/oracle_ex/sql_ex
cd ~/oracle_ex
```

구조는 다음처럼 만든다.

```text
oracle_ex/
├── compose.yml
└── sql_ex/
    └── 01_create_joy.sql
```

---

# 3. `compose.yml` 작성

`~/oracle_ex/compose.yml`

```yaml
services:

  oracle:
    image: container-registry.oracle.com/database/free:latest-lite
    container_name: oracle-free

    ports:
      - "1521:1521"

    environment:
      ORACLE_PWD: Oracle1234
      ORACLE_CHARACTERSET: AL32UTF8

    volumes:
      - oracle_data:/opt/oracle/oradata
      - ./sql_ex:/opt/oracle/scripts/setup

    restart: unless-stopped

volumes:
  oracle_data:
```

Oracle 공식 문서에서도 `container-registry.oracle.com/database/free:latest-lite` 이미지를 사용하고 있으며, `1521` 포트와 `/opt/oracle/oradata` 볼륨 구성을 안내하고 있다. 

### 관리자 계정

위 설정으로 다음 계정에 동일한 비밀번호가 적용된다.

```text
SYS       / Oracle1234
SYSTEM    / Oracle1234
PDBADMIN  / Oracle1234
```

즉 SQL 실습에서는 `SYSTEM`을 관리자 계정으로 사용하고, 정말 필요한 관리 작업에서는 `SYS AS SYSDBA`를 사용하면 된다.

# 4. joy 사용자 생성

`sql_ex/01_create_joy.sql` 파일을 만든다.

```sql
ALTER SESSION SET CONTAINER = FREEPDB1;

CREATE USER joy
IDENTIFIED BY Joy1234
DEFAULT TABLESPACE USERS
TEMPORARY TABLESPACE TEMP
QUOTA UNLIMITED ON USERS;

GRANT CREATE SESSION TO joy;
GRANT CREATE TABLE TO joy;
GRANT CREATE VIEW TO joy;
GRANT CREATE SEQUENCE TO joy;
GRANT CREATE PROCEDURE TO joy;
GRANT CREATE TRIGGER TO joy;

EXIT;
```

Oracle 공식 컨테이너는 `/opt/oracle/scripts/setup` 경로에 배치된 SQL 또는 Shell 스크립트를 초기 DB 구성 후 실행할 수 있다.  
SQLD 실습에는 이 정도 권한이면 충분하다.

---

# 5. Oracle 실행

```bash
cd ~/oracle_ex

docker compose up -d
```

상태 확인:

```bash
docker compose ps
```

또는

```bash
docker ps
```

---

# 6. 최초 실행 로그 확인

```bash
docker compose logs -f
```

다음 메시지가 나오면 DB가 준비된 것이다.

```text
DATABASE IS READY TO USE!
```

Oracle 공식 문서에서도 이 메시지를 정상 구동 기준으로 안내하고 있다. ([Oracle Docs][2])

로그 화면만 종료하려면:

```text
Ctrl + C
```

컨테이너는 계속 실행된다.

---

# 7. Oracle 내부에서 접속 확인

먼저 `SYSTEM` 계정으로 접속한다.

```bash
docker exec -it oracle-free \
sqlplus system/Oracle1234@FREEPDB1
```

정상적으로 접속되면 다음 SQL을 실행한다.

```sql
SELECT SYS_CONTEXT('USERENV', 'CON_NAME')
FROM DUAL;
```

결과:

```text
FREEPDB1
```

Oracle Free 기본 PDB가 `FREEPDB1`인 것은 공식 문서에서도 확인할 수 있다. ([Oracle Docs][1])

---

# 8. joy 계정 확인

```sql
SELECT username
FROM dba_users
WHERE username = 'joy';
```

정상이라면:

```text
USERNAME
--------
joy
```

SQL*Plus 종료:

```sql
EXIT;
```

JOY 계정으로 직접 접속한다.

```bash
docker exec -it oracle-free \
sqlplus joy/Joy1234@FREEPDB1
```

확인:

```sql
SHOW USER;
```

```text
USER is "joy"
```

# 9. JOY 계정 테스트

```sql
CREATE TABLE student (
    student_id NUMBER PRIMARY KEY,
    name       VARCHAR2(50),
    age        NUMBER
);
```

데이터 입력:

```sql
INSERT INTO student
VALUES (1, '홍길동', 25);

INSERT INTO student
VALUES (2, '김철수', 27);

COMMIT;
```

조회:

```sql
SELECT *
FROM student;
```

정상적으로 조회되면 실습 환경은 완료된 것이다.
